# Power Requirements

Teensy: recommended max 3.3V load = 250mA

4.0 uses 100mA itself

TLV75733PDBVR rated for 1000mA

GPS:  25mA tracking, 20mA navigating

3.3 or 5V  (has onboard 200mA linear regulator)

Curr Sense:

3.3V,   10mA  (14mA max)

RS232:

3.3V,40mA (transmitting at 118KHz)

1mA no TX

CAN3: TCAN334

3.3V  60mA high load dominant

3.5mA recessive

180mA dominant with bus fault

20uA standby mode

CAN1: SN65HVD230

10mA no Load

18mA at 1Mbps

Opamps:  200uA quiescent per channel
